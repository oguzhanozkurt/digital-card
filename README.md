# ITOC360 Digital Business Card

Files:
- index.html — mobile digital business card
- profile.jpg — profile photo
- mehmet-oguzhan-ozkurt.vcf — Save Contact file

## Publish with GitHub Pages
1. Create a new public repository, e.g. `digital-card`.
2. Upload all three files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will show the published URL after deployment.

After the final public URL is known, generate the QR code from that URL. Use the same URL later for the NFC tag.
